# Claude hook bridge (HI-W2-1..3, HI-WIRE) and installed-host smoke plan

## What exists

- **Plugin** `plugins/claude/`: `.claude-plugin/plugin.json` (name, version, description, license; `hooks/hooks.json` is auto-discovered, so it is not referenced again), `hooks/hooks.json`, `commands/capabilities.md` (`/receipts:capabilities`, display only), `skills/receipts/SKILL.md`, `bin/receipts-hook`.
- **Launcher** `bin/receipts-hook`: POSIX sh; execs `$RECEIPTS_BIN` (must be absolute) or `$CLAUDE_PLUGIN_ROOT/bin/receipts` with `hook claude <Event>`. Hook JSON stays on stdin; the event is the fixed literal from `hooks.json`. No PATH lookup, eval or interpolation. With no binary, observers exit 0 and `WorktreeCreate` exits 1.
- **Binary** `receipts` (`crates/receipts-cli/src/bin/receipts.rs`): only `hook claude <Event>`. Reads stdin up to 1 MiB + 1 byte and only `CLAUDECODE`, `CLAUDE_PROJECT_DIR`, `CLAUDE_PLUGIN_ROOT`, `CLAUDE_PLUGIN_DATA`, `RECEIPTS_CLAUDE_EXECUTABLE`.
- **Registered hooks and mapping** (`src/hosts/claude/hook_map.rs`): SessionStart→HOST_SESSION_STARTED, SessionEnd→HOST_SESSION_ENDING, PostToolUse→TOOL_EXECUTED, PreCompact/PostCompact→CONTEXT_COMPACTED (HOST_HOOK, OBSERVED); WorktreeCreate→WORKSPACE_CREATED after creation (CORE_DRIVEN; INFERRED for the plain no-task path). WorktreeRemove is handled but emits nothing.
- **Not registered**, because the frozen source policy forbids the HOST_HOOK class for their mapped events: FileChanged (WORKSPACE_CHANGED is WORKER_DISPATCH), SubagentStart/Stop (ROLE_EXECUTOR_* are CORE_DRIVEN), TaskCompleted (WORKER_DISPATCH). The `CLAUDE_HOST_ADAPTER.md` table and `NORMALIZED_HOST_EVENTS.md` source classes disagree on these rows; A1 decides.
- **Spool** `<CLAUDE_PROJECT_DIR>/.receipts/inbox/host-events.jsonl`: one HI-WIRE event per line; directories `0700`, file `0600`, `O_APPEND|O_NOFOLLOW|O_NONBLOCK`, owner/mode/link-count checks, 64 KiB line and 64 MiB file bounds, single write then `fdatasync`. No State access exists in Host or CLI source. Ingestion is HI-W4-1.
- **Exit contract**: observers always exit 0 with empty stdout (one stderr line on refusal). WorktreeCreate prints exactly `<absolute path>\n`, or exits 1 with a reason. Exit 2 is never used.
- **WorktreeCreate**: `<toplevel>/.claude/worktrees/<name>` on `worktree-<name>`, base = HEAD read from Git's own files. Then Workspace `WorktreeCreateRequest::create` with no task context (W2 has no core task supplier). Workspace refusals (existing data, conflicting branch or registration, untrusted config) abort creation as-is; there is no second path. Synthetic p50 ≈ 0.18 s, p95 ≈ 0.30 s (10 runs on this Mac; budget 5 s).
- **WorktreeRemove**: Q-02 (2.1.246) showed that with a custom WorktreeCreate, Claude leaves removal to the hook. Workspace has no verified removal for plain worktrees, so the hook deletes nothing: it preserves the tree and names it on stderr. Leftover worktrees therefore need manual `git worktree remove` until Workspace adds that API (cross-lane request).
- **Capability observation** (`host_capability_observation*.rs`): plugin-list success → hooks supported. The installed plugin's `hooks/hooks.json` (read no-follow from the probe-reported absolute `installPath`) gives configured events, required coverage and `hook_definition_digest`. Claude has no hook trust model (`hook_trust_required=false`, `hooks_trusted=null`). Files only refute (`disableAllHooks`, managed `allowManagedHooksOnly`, plugin reported disabled). Enablement and admin admission are proven only by a Receipts hook process whose `CLAUDE_PLUGIN_ROOT` equals that install path. A refutation that contradicts a live hook stays unknown. COMPLETE requires a complete fingerprint and every load-bearing fact.
- **Cache**: SessionStart (only when `RECEIPTS_CLAUDE_EXECUTABLE` and `CLAUDE_PLUGIN_DATA` are absolute) observes fresh, then writes `<CLAUDE_PLUGIN_DATA>/host-capability-report.json` (`0600`, atomic rename). The prior file is reused (keeps `probed_at`, advances `last_verified_at`) only when it equals the freshly selected report. That report embeds the fingerprint token, so any material drift, a forged token or a different selection forces a re-probe. Incomplete observation removes the file.
- **Codecs** (`src/hosts/wire/`): strict `HostCapabilityReport` and `NormalizedHostEvent` JSON. All 8 positive fixtures round-trip; all 13 negatives are rejected. A decoded report must match the frozen selector's derivation or satisfy the consistency rules.
